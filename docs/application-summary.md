## Short project description

I worked on a university team project to develop an automated sunny-side-up egg-frying machine for breakfast service. My main contribution combined mechanical CAD with component selection, functional calculations, material and manufacturing choices, the final BOM, and technical assembly drawings. I also created the functional structure and full workflow explanation. The project remained at the design stage.
