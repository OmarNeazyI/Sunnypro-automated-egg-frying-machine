# Native CAD source

The documentation package is accompanied by the original native source archive, delivered separately as SunnyPro_Original_CAD.zip. It contains the SolidWorks parts, assemblies, and native drawing received for this project.

The original CAD files and their internal names have been retained to avoid breaking component references. The archive includes distinct assembly revisions and an AutoRecover-named drawing; they have not been deleted without a verified dependency check.

## Opening the source

Extract the companion archive into one working directory and open Main Assembly.SLDASM. Keep the other parts and assemblies available in that directory. The source drawing PDF identifies SolidWorks 2025 SP3.0 as its exporter.

The complete assembly is large. The original report notes imported-component section warnings, long rebuild times, and occasional incomplete drawing views. Use the [assembly PDF](../docs/drawings/SunnyPro_Assembly_Drawing.pdf) as the reference for the exported layout.

The native assembly and drawing have not been opened or rebuilt in SolidWorks during documentation preparation. Their reference resolution, mates, and motion studies have not been independently validated.

## File status

The companion archive is preserved byte-for-byte. It is an original source archive, not a cleaned or privacy-sanitised CAD release. Native metadata may contain author, workstation, file-path, or revision information. Public document copies have been treated separately.
